Preset semantics are deterministic: registry defaults are prepended, but an explicit user option with the same long-option name replaces the preset. Both split (`--backend python`) and inline (`--backend=python`) forms are tested. All listed stage-3 model IDs implement `--smoke-test --output-dir`, force CPU/Agg with a fixed seed, and atomically write strict JSON with finite state, iterations, residual, convergence, measured positive contact force/count, nonzero state increment, mesh path/face count where applicable, and per-variant timing evidence. Smoke execution calls each registered production module's own initialization, contact, and implicit/Newton step; no surrogate solver is used.
